## 简介

- 🀄本项目旨在持续汇集 GitHub 上的 [Obsidian](https://obsidian.md/) **原生中文插件**和**自带中文翻译**的活跃插件，为中文用户提供一个发现、安装和参与贡献的中文资源索引。

## 新手入门

第一次用 Obsidian 或第一次装社区插件？按下面三步即可：

1. **开启社区插件市场**：打开 Obsidian → `设置` → `第三方插件` → 关闭「安全模式」→ 点击「浏览」即可搜索并安装插件。
2. **装社区商店里搜不到的插件**：部分小众或刚发布的中文插件可能还没进官方市场。可先装一个支持「通过 GitHub 仓库地址安装」的安装器，再粘贴插件仓库地址（形如 `用户名/仓库名`）即可安装。
3. **装中文主题**：到 `设置 → 外观 → 主题 → 管理 → 打开社区主题市场` 搜索本列表「精选中文主题」里的主题名即可一键应用。

> 提示：社区插件与主题都保存在你的本地库里，随时可在「第三方插件 / 外观」里停用或卸载；不确定的插件，先用一个测试库试用更稳妥。

## 社区汉化指引

**无需代码背景，你也可以为社区做贡献！**

许多热门的国际插件都开放了社区翻译。通过简单的步骤，你就可以帮助它们更新中文语言文件，让更多中文用户受益。

- **通用教程**：
    1. 在插件的 GitHub 仓库中找到语言文件目录（通常名为 `lang`, `locale`, `i18n`[^1], `l10n`[^2]）。
    2. 找到中文文件（如 `zh.json` 或 `zh-cn.ts`）。
    3. 参考同目录下的英文文件 (`en.json`)，将未翻译的或翻译不佳的文本进行修改。
    4. 通过 `Pull Request` (PR) 将你的修改提交给原作者。
    5. 等待作者审核合并。
- **译名参考**: 为了保持一致性，请参考 [Obsidian 官方翻译库中的常用译名](https://github.com/obsidianmd/obsidian-translations/blob/master/translations/zh.txt)。

## 贡献指南

我们欢迎所有用户参与共建，让这个列表变得更好！

如果你发现或开发了优秀的中文插件/主题，或希望对现有条目进行补充修改，请通过 **[提交一个 Issue](https://github.com/PKM-er/awesome-obsidian-zh/issues)** 或提交 Pull Request。

**提交标准:**

1. **强相关性**: 插件/主题由中文开发者主导，或对中文环境有特别优化，或拥有高质量的中文翻译。
2. **可用性**: 插件/主题在 Obsidian 最新版中可稳定运行。新条目先进入「新插件观察区」，建仓满 30 天且有 5 个以上 Star 或 500 次以上下载后，自动转入主题表格；建仓满 120 天仍不足 3 个 Star、200 次下载且 180 天没有更新的条目会被自动移出。
3. **遵循格式**: 提交时请参考本文档的表格格式。

> 多数条目由脚本从 Obsidian 社区插件市场自动筛选，升降档也由脚本自动完成，没有人工闸门。因门槛被挡但有实际用户或中文适配的插件，欢迎在 Issue 中说明。
